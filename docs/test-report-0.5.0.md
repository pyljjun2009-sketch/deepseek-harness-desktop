## 已发现的问题

候选版桌面启动实际失败，隔离诊断确认是 `late-protocol-registration`：恢复模块异步准备后才导入官方壳，使界面协议注册晚于 Electron ready。现已在同步入口注册，并使用同进程确认避免重复注册；新增回归与官方专项 123 项通过，实际中文 UI 已启动。不将前两轮安装包标为合格发行版。

第一次真实恢复资格测试只有 3 分钟总预算，完整快照刚开始就超时；没有开始三轮崩溃，不计为通过。随后短路径实机检查进一步发现普通 Electron fs 将 app.asar 虚拟为目录（isFile=false/size=0，物理读取 ENOENT），original-fs 才能读取其真实 126,448,970 字节。恢复模块已改用原始物理接口，并新增真实 Electron 回归；旧候选不据此获判合格，必须重新打包后复测。[Electron 官方 ASAR 说明](https://www.electronjs.org/docs/latest/tutorial/asar-archives)

完整隔离安装 probe 发现入口拒绝新建空目录；builder 在 customInit 之前 SetOutPath 会创建目标，而 FileExists 通配符把空目录也视为存在。现已改为只读原生枚举、立即读取错误码并校验规范化根别名，10/10 真实 fixture 通过；失败的完整 probe 不计为安装通过。

后续完整 probe 发现 electron-builder 即使接收 prepackaged 输入也会向其写入 elevate.exe 等 NSIS 元数据。原载荷完整性门禁在安装前拦截了该变化，未执行安装。重新封装改为使用独立 UUID 完整副本，并校验原载荷不变；副本只允许固定 builder 的 elevate.exe 和受限的本仓库更新源元数据变化，最终安装与恢复验收绑定该最终副本的全树摘要。中断的封装没有候选记录，不计为资格通过。

最终完整载荷的恢复和 UI 并行验收暴露官方 Host 默认固定 `19387`：独立数据槽没有隔离 TCP 端口，第二个实例以 EADDRINUSE 失败。旧报告虽完成完整快照与三次退出动作，但最终缓存 Host 健康阶段超时，报告 passed=false，不能计为完整恢复通过；其自有主进程和看门狗均确认清理，原候选载荷未改变。现采用 Host 端口 0、由系统自动分配回环端口的最小修复，重新编译/打包/更新冻结锁/生成摘要，禁止直接改已密封载荷。新包并行实例健康、三次真实崩溃回退及完整安装事务均已重新通过，见 ADR 0008。

完整回归首轮在安装/双快照高 I/O 并行负载下有两项旧兼容 fixture 超过默认 5000ms，23/25，exit 1。保留失败日志；未更改超时时限，待重负载结束后整套重跑 25/25、exit 0。不会把首轮计为通过。旧候选 UI 正常退出测试的 7 秒进程消失断言未通过，退出标记已写入、Host 已关闭；当时进入纯 Electron/真实桌面独立对照，不将该轮判为正常退出合格。

旧候选独占生产配置的第二次正常退出也未通过，真实进程句柄等待 60 秒失败；无看门狗的真实桌面退出及纯 Electron 对照通过。仅结束已核对身份、退出标记匹配的自有看门狗后，主进程 265 毫秒内自行退出，未请求强制结束主进程。随后采用每轮存活检测先响应本轮干净退出标记的最小修复，保持正常用户退出在真正 quit 后才写标记，不跳过官方确认/清理；原有受控 bootstrap 故障恢复路径不变。此诊断不计正常退出通过，当时要求新包全部重新验收；本轮的新安装、崩溃及两次严格正常退出重新通过，见表格及 ADR 0009。

新候选第一轮 UI 检查通过，但退出观察脚本用 PowerShell 5 默认编码读取带中文路径的 UTF-8 JSON，在准备进程句柄观察前解码失败。虽然后续确认主进程和看门狗已消失，仍不能据此补造 WaitForExit 证据，本轮不计严格正常退出通过。仅修正忽略目录内的测试脚本为显式 UTF-8 读取，并要求观察器 ready 后才关闭窗口；保留该失败记录，使用全新生产目录重测。

打包工具会改写部分 package.json 元数据，导致暂存 receipt 与最终 ASAR 不同。现已按固定 builder 版本提前规范化；生产入口、exports 和依赖保留。`npmRebuild:false` 跳过 beforeBuild hook 的问题也已纠正为 hook 显式拒绝重建并使用已物化闭包。OneDrive/杀软短暂占用导致的 Windows 构建目录 rename 错误通过仅限暂态错误、目标仍不存在的有界重试处理；耗尽仍失败，不覆盖已有目标。

没有用真实模型负载测量 token 节省比例，因此不宣称百分比。快照完整性不是代码签名；社区安装包不会继承官方签名。

首次健康晋升前没有已验证快照。没有快照、快照损坏，或当前安装与稳定缓存均无法被操作系统启动时，恢复只能停止并保留记录；后台看门狗不保证能显示提示窗口。安装目录切换是两次重命名，不是断电原子交换。失败版本的新会话留在失败槽，不自动合并。
