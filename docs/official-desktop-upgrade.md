## 开发与复现

Windows x64，Node 24，Git 和 root npm ci。推荐把官方源构建到短路径，避免 Windows 的长路径问题。

```powershell
$env:DSH_OFFICIAL_SOURCE = 'C:\DSHB\harness-020rc2'
npm run test:recovery
npm run build:official
npm run dist:official
```

脚本检查锁定提交、安装冻结依赖、应用 desktop/official-overlay.patch、编译官方 Host 与工作台、准备完整运行时、部署生产闭包并打包。构建记录保存在忽略的 .official-build/paths.json。完整准备完成后，`node scripts/build-official.mjs --stage-only --package` 可以复用已校验资源，不能跳过第一次准备。

仅重新封装 NSIS 时可运行 `npm run dist:official:repackage`，它会再次验证运行时、ASAR 壳闭包、物理 PE、Host/Office 功能和当前恢复入口。NSIS 在独立 UUID 副本上封装，原始载荷全树摘要必须保持不变；副本只允许固定 builder 的提权辅助程序和受限的本仓库更新元数据变化，最终副本的完整摘要写入候选记录并用于资格测试。恢复入口改动必须先重新生成载荷，旧载荷不能直接复用。`npm run dist:win` 已指向官方构建；旧监督壳只通过显式 `dist:legacy` 构建，根 package 的 0.4.0 是旧壳工具版本，不是新安装包版本，新发行版本以 official.lock.json 为准。

SheetJS 官方 CDN 超时时，可用 scripts/download-verified.mjs 进行有界分段下载，最终必须匹配上游 SHA-512。DSH_SHEETJS_CACHE 指定已校验本地包时使用 pnpm transport hook，仅替换获取路径，不修改依赖版本或冻结锁文件。GitHub 发布文件使用 scripts/download-github-asset.mjs 经官方 API 获取明确允许的 CDN 端点，固定大小和 SHA-256 必须匹配；签名下载地址不写入日志。

官方 Electron 包自带的 checksums.json 受冻结 npm 锁保护；即使复用缓存仍执行官方 SHA-256 校验，不禁用校验。生产运行时另外保留最终 pnpm-lock.yaml 与包集清单，再一并纳入运行时全树摘要。首次构建会产生该生产锁，已有 official-runtime.lock.yaml 时后续准备使用冻结锁；重现核心输入还需固定提交重新构建的核心 tarball 哈希与包集一致。

## 数据与恢复

沿用本项目的 Electron userData 根目录。官方恢复记录位于 official-recovery/state.json（含原子写和 .bak）；数据位于 official-homes/<槽>；完整稳定安装位于 stable-releases/<版本>。绝不改写全局 %USERPROFILE%\.dsh。

从旧版托管槽仅复制共享数据；旧 executable profiles 不自动迁移，避免加载过时插件。旧 recovery、harness-home、profile-homes 和会话文件不会被删除。用户需要的自定义插件应在官方界面重新安装。回退的数据槽独立，失败版本期间的新会话保留在失败槽，不能自动合并。

启动失败最多按“重试 → 备份并禁用第三方插件 → 旧稳定安装”恢复；没有可用快照或当前安装与稳定缓存均无法启动时停止重试并保留记录。仍能显示界面的进程会提示修复，后台看门狗不能保证弹窗。不会把新运行时和旧壳混用，也不会让旧版打开新版数据槽。

稳定晋升前持续进行 45 秒本地认证 RPC 健康检查（单次超时 3 秒），不调用模型；连续三次失败触发恢复。完整缓存带有 SHA-256 文件/目录清单，自动回退前必须全部匹配。损坏或无清单的历史缓存不会被自动启动，原目录仍保留。

安装包先完整解压到独立 GUID 目录，再切换完整安装；普通解压/文件占用/切换失败保留旧目录。断电或强制结束安装可能留下临时完整目录，两次目录重命名不是原子的磁盘交换；不将此机制声称为断电后自动启动的保证。

安装/卸载不会主动结束任何同名进程。检测到 DeepSeekHarness.exe 仍运行，或探测结果不可靠时，提示用户手动退出并停止操作；同名无关程序也可能造成保守拒绝。这是在安全检查技能的最小权限原则下选择的失败关闭行为。完整稳定缓存约需额外 1 GB 磁盘空间；首次 45 秒观察期结束后还要完成复制及摘要，不能仅按 45 秒认定恢复副本已经就绪。恢复物理文件操作使用 Electron original-fs，不改变全局 ASAR 支持。

社区 Host 默认使用端口 0，由系统在启动时自动分配可用的本机端口，不再固定使用上游的 19387。仍只监听 127.0.0.1，认证和桌面转发沿用官方 ready URL。不要在非官方脚本中写死内部端口；用户显式插件 patch 仍可覆盖端口，此修复不会自动改写用户配置。并行实例与异常恢复必须在新载荷上重新验证，见 ADR 0008。

## 本机人工验收

候选版不通过自动更新替换 0.4.0。手动安装前，先备份需要保留的桌面数据，并用 `Get-FileHash -Algorithm SHA256` 核对安装包与 Release 的 SHA256SUMS；从应用菜单完全退出现有程序，再运行安装器。不要删除全局 `.dsh` 或独立 Sub2API 来解决安装问题。

在不输入 API 密钥的情况下，可以先检查中文欢迎页，点击“稍后配置”进入工作台，打开设置，然后用一个无敏感文件的本机测试目录检查原生文件夹选择。最后从“应用”原生菜单选择“退出”，确认程序确实结束且不会自行重启，再重新打开。原生菜单退出和文件夹对话框是当前自动测试未覆盖的人工发行门槛；如失败，保留截图和桌面恢复记录，不将候选晋升到稳定通道。

欢迎页正常关闭的生产退出测试，与工作台原生菜单退出不是同一项验收。自动恢复压力测试只在隔离测试目录执行，不建议为了验收而强制结束真实会话。
