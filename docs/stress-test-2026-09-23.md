# v0.3.1 多轮压力与恢复测试（2026-09-23）

环境：Windows 10.0.26200、Electron 44.0.0、捆绑 DSH 0.1.1-rc.2。所有安装包测试均使用临时 DSH 数据槽与本机回环地址；未读取真实 Sub2API 账号、发起模型请求或消耗额度。

| 测试 | 轮次与负载 | 结果 |
| --- | --- | --- |
| 单元测试 | 连续 20 轮，每轮 24 项，共 480 次用例执行 | 20/20 轮通过 |
| 插件与恢复并发请求 | v0.3.1，10 轮；每轮启用插件与故障恢复后各 100 个并发 HTTP 请求，共 2,000 次 | 2,000/2,000 成功；10/10 轮持久化恢复状态正确 |
| 高峰并发请求 | v0.3.1，3 轮；每轮两阶段各 200 个并发 HTTP 请求，共 1,200 次 | 1,200/1,200 成功；3/3 轮恢复通过 |
| 监督器进程故障 | v0.3.1，实际终止 DSH 子进程 3 次，等待自动重启 | 3/3 次重回在线，Sub2API 优先自动停用 |
| 完整安装包回归 | v0.3.1，连续 3 轮；检查目录选择器、插件注册、账号允许列表、坏候选拒绝、数据槽隔离与回滚 | 3/3 轮通过 |

100 并发的单阶段本机请求耗时为 80–222 毫秒；200 并发为 167–224 毫秒。这是回环接口的阶段总耗时，不是模型推理吞吐量或公网性能承诺。压力测试期间发现并修复了监督器启动成功后仍保留 45 秒超时计时器的问题；修复后压力脚本结束即正常退出。测试未发现遗留的 `dsh-desktop-stress-*` 临时目录。

复现命令：

```powershell
npm run verify
npm run pack
$env:DSH_STRESS_ROUNDS='10'
$env:DSH_STRESS_CONCURRENCY='100'
$env:DSH_SUPERVISOR_ROUNDS='3'
npm run stress:packaged
npm run smoke:packaged
```

限制：本次只覆盖桌面版所捆绑的运行时、插件注册、恢复管理器和监督器，不包含真实账号的额度调用、模型输出正确性，也未在一台全新 Windows 设备上完成图形安装器交互测试。这些仍需要具备相应环境的端到端验证。
