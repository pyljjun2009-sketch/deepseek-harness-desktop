# ADR 0006：以官方桌面源码替换旧监督壳

日期：2026-10-08。状态：实施中；安装包验证完成前不替换 0.4.0 稳定发布。

## 背景

用户要求根据 DeepSeek 官方桌面端重新制作项目。官方已提供 Windows/macOS 桌面下载，公开源码位于 deepseek-ai/deepseek-harness 的 apps/desktop。官方桌面包含欢迎页、本地工作台、Host 生命周期、目录选择、账号设置、插件恢复及更新流程。旧项目只捆绑 0.1.1-rc.2 CLI，继续拼接这些功能会形成两套维护路径。

## 决策

锁定官方 dsh-v0.2.0-rc.2 提交 639ed015397290b3745d163aafe02ffee4aa3f84；不跟随 alpha。使用官方工作台和 Host，以中文为默认语言，取消旧管理器与第二工作台窗口。保留少量可审查补丁和独立恢复启动器，分发名称明确为社区恢复版，不冒充官方安装包。

官方源码、pnpm 和 Electron 版本由 official.lock.json 记录。使用上游冻结锁文件、生产树完整性检查、Host 和 Office 运行时冒烟验证；不删除失败依赖来绕过验证。更新地址只指向本项目 GitHub Release，不使用官方签名发布通道。壳和运行时一起升级，不再单独替换 npm latest。

恢复按完整安装与对应数据槽成对选择：一次故障重启，第二次使用官方插件禁用和备份操作，第三次回退到仍存在的上一稳定安装。首次安装无历史快照时保留数据、停止无限重试并提示修复。正常运行观察期结束后保存完整安装快照，保留上一稳定版。外部看门狗覆盖主进程异常退出；正常退出和更新不会触发重启。

稳定晋升要求 45 秒持续认证 HTTP RPC 检查、至少三次新鲜样本和有效工作台窗口。检查仅查询本地策略，不访问模型；单次失败重置观察期，连续三次失败走同一有界恢复流程。复制安装快照期间仍持续采样，并在提交前检查健康 generation。

稳定快照建立全文件及目录 SHA-256 清单，清单摘要绑定到对应版本/数据槽；回退前完整校验。历史无清单缓存保留但不自动启动，当前健康安装可重建并留存旧目录。此校验用于发现意外损坏，不替代签名。主状态损坏后不得覆盖最后有效备份。稳定安装只读，进程设置 PYTHONDONTWRITEBYTECODE 避免写入捆绑 Python 目录。

不改写 ~/.dsh、不读取账号密钥、不恢复 Sub2API 集成。升级使用共享数据副本，官方版本重建 executable profiles；旧版插件配置留在原槽，不自动装入新版。坏版本数据槽保留，回退不把新数据合并进旧版。

## 影响及限制

优点：官方界面与功能同源；API 和桌面 Host 的升级边界更清晰；应用无法启动时仍可选完整旧安装。

代价：完整官方构建比旧壳大，需要固定 Node/pnpm、原生组件、Python 与 Office 资源。快照占用额外磁盘空间。首次安装没有已验证的旧版本，不能凭空制造回退快照。安装包未签名，不继承官方发行方签名或信任。

不声称通用 token 节省百分比。使用官方上下文压缩与工具输出保留机制，旧版阈值补丁不盲目套用到新配置模型。

## 验证要求

恢复状态单元测试、连续升级/回退循环、官方桌面关键测试、完整生产构建和生产树校验、打包后 Host/UI 启动、中文路径目录选择、干净安装及退出/崩溃恢复测试全部通过，才生成可推荐安装的 Release。
