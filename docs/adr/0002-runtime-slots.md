# ADR-0002: 运行时采用候选槽与最后稳定槽

## 状态

Accepted

## 背景

DSH 仍处于 RC 迭代期，插件组合也可能对新版本不兼容。原地 `npm update -g` 无法可靠回退。

## 决策

保留捆绑、候选和 last-known-good 三个角色。新版本安装到独立目录，经过 CLI、配置、HTTP 和观察期验证后才晋升。

## 后果

### 正面

- 切换指针即可回滚，用户配置零迁移。
- 可明确区分下载成功、可启动和生产稳定。

### 负面

- 磁盘会同时保留多个运行时。
- 需要谨慎处理 Windows 进程锁和旧版本清理。

## 备选方案

- 全局 npm 原地升级：简单但无法保证回滚。
- 复制整个 `~/.dsh`：恢复粗暴且可能覆盖用户新数据，因此拒绝。
