# ADR 0006：Sub2API Personal 作为按需工具

状态：已采纳（2026-09-23）

## 背景

用户希望复用本机 `dsh-sub2api-personal`，但只在需要时调用。桌面版以稳定恢复为首要目标，不能让可选工具污染全局 `~/.dsh` 或成为捆绑运行时的启动前提。源项目为 MIT 许可，集成的是其 DSH 工具入口，而非 MCP 服务或模型提供商配置。

## 决策

- 将审阅过的 0.4.2 DSH 工具入口及其许可随桌面安装包打包，保持源文件独立；与捆绑 DSH 对齐的 `@deepseek-ai/dsh-tools` 作为应用依赖。
- 默认关闭。启用时先从本机客户端读取账号，仅接受明确勾选的账号名，并在临时 DSH 数据槽做 Web 启动预检；成功后通过桌面专属 patch 挂载工具。
- 只通过环境变量传递允许列表、PowerShell 可执行文件路径和本地客户端路径。工具的请求体由源插件写入临时文件后调用客户端；桌面 IPC 不接收密钥或任意命令。
- 不改默认聊天模型，不安装或覆盖本机 `sub2api-personal` 客户端，不改动全局 DSH profile。工具只在 Agent 调用时工作，额度和请求取决于所选账号。
- 启动依赖缺失时自动关闭此集成；运行时失败时优先停用此插件并重试，然后才关闭省 token 层或回滚候选版本。禁用状态与恢复状态原子持久化。

## 兼容性与限制

本机仍需提供 PowerShell 7、`sub2api.ps1` 和有效账号配置。桌面版只保证插件注册和 DSH Web 启动的预检；不能在发布测试中使用用户的真实账号或额度。源插件与未来 DSH API 可能不兼容，因此升级候选继续经过配置和 Web 预检，插件故障可独立停用。安装包不提供自动 Sub2API 账号迁移。
