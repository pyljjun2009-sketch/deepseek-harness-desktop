# ADR 0007: 社区版安装包先完整解压再切换目录

## 状态

已实现构建适配；真实安装与失败注入验证通过之前不发布。

## 背景

应用内部的恢复逻辑只有在 Electron 与入口脚本仍完整时才能启动。直接覆盖安装目录会使安装中断破坏恢复入口。旧安装包的固定 74 字符安装路径限制也不能作为新官方运行时的有效证据。

## 决定

复用固定官方提交中的 NSIS 目录切换算法，修改根项目实际使用的固定版本 electron-builder。先使用完整 7za 程序将负载解压到本次安装专属的 GUID 目录，然后将现安装目录改名备份、将完整候选目录提升为安装目录；普通解压、重命名或取消失败恢复前代安装。保留上游注册、快捷方式、卸载界面及可选用户数据处理；默认卸载不删除用户数据。只允许当前用户安装，拒绝磁盘、共享根目录与未登记的非空目录。动态扫描成品物理路径，拒绝链接，并记录最长相对路径，最终用实际安装验证长路径支持。

## 影响

完整 7za 和许可文件增加安装包体积。构建模块必须与根项目的 app-builder-lib 实例一致，否则原型补丁不会生效；遇到版本或模板变化拒绝构建并重新审核。GUID 临时路径额外增长 43 个字符，不能沿用旧解码器的固定路径预算。强制终止安装程序或断电可能留下完整临时目录或备份；两次目录重命名不是文件系统原子的交换，不能把该机制声称为断电后自动启动保证。此机制与独立应用恢复缓存结合，真实安装与故障注入结果分别记录。
