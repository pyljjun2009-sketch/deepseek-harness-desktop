# DeepSeek Harness Desktop 架构

## 目标

### 功能

- 启动、停止、重启和打开官方 DeepSeek Harness Web 工作台。
- 显示运行时版本、健康状态、运行时长、崩溃与回滚次数。
- 检查 npm 官方通道版本，安装候选版本并在失败时自动回滚。
- 管理开机启动、稳定/预览通道和诊断日志。

### 非功能

- 恢复时间目标：已运行实例异常后 15 秒内重启；启动中的候选在 45 秒超时后回到上一稳定版。
- 恢复点目标：升级不修改托管 profile 和会话数据，RPO 为 0。
- 安全：渲染进程无 Node 权限；IPC 白名单；Harness 仅监听环回地址。
- 兼容：DSH profile 与插件配置保持原格式；桌面端通过独立 `DSH_HOME` 管理，避免全局插件污染恢复基线。
- 可维护：桌面壳、监督器、升级策略和 Harness 运行时分层。

## 高层结构

```text
┌──────────────────────── Desktop renderer ────────────────────────┐
│ 状态 / 升级 / 恢复 / 日志（sandbox + contextIsolation）          │
└───────────────────────────┬──────────────────────────────────────┘
                            │ narrow IPC
┌───────────────────────────▼──────────────────────────────────────┐
│ Electron main                                                  │
│ RuntimeManager ─ Supervisor ─ RecoveryStore ─ UpdateDiscovery  │
└───────────────┬───────────────────────────┬──────────────────────┘
                │ child process             │ atomic state
┌───────────────▼────────────────┐    ┌─────▼─────────────────────┐
│ DSH runtime slot              │    │ userData                  │
│ bundled / candidate / LKG     │    │ runtimes / logs / state  │
└───────────────┬────────────────┘    └───────────────────────────┘
                │ loopback HTTP
┌───────────────▼────────────────┐
│ Official DSH Web UI + profiles │─── reads/writes ─── userData/harness-home
└────────────────────────────────┘
```

## 失败模式

| 失败 | 检测 | 恢复 |
|---|---|---|
| 候选 CLI 不可执行 | 烟测退出码/超时 | 删除 staging，保持当前版本 |
| 用户插件与候选不兼容 | `--dump-config` 失败 | 不激活候选 |
| 候选启动即退出 | 进程 exit | 先关闭优化层重试，仍失败则切回 LKG |
| HTTP 服务失活 | 连续 3 次探测失败 | 终止进程树并执行恢复策略 |
| 稳定运行时瞬时崩溃 | 进程 exit | 指数退避重启，最多 3 次/5 分钟 |
| 托管稳定版持续崩溃 | 崩溃窗口 | 回落到捆绑运行时 |
| Renderer 崩溃 | `render-process-gone` | 重建本地管理窗口 |
| Desktop 主进程崩溃 | 外部 watchdog | 重新启动桌面程序 |
| 状态文件损坏 | JSON 校验失败 | 读取 `.bak`，再回落到默认安全状态 |
| Windows 安装路径过长 | 安装前检查目标路径 | 拒绝安装并要求选择更短目录，避免 NSIS 静默遗漏依赖 |

## 升级兼容策略

- `stable` 只跟随 npm `latest`；`preview` 才跟随 `alpha`。
- 每个运行时目录不可变，升级是增加槽位与切换指针，不是原地覆盖。
- 状态文件带 `schemaVersion`，未来迁移必须保持向后读取。
- 捆绑版本永远可用作恢复地板；清理旧槽位时禁止删除 active、candidate、LKG。
- DSH 以普通文件而非 ASAR 发布，以兼容运行时插件的链接与加载机制。
- 升级安装器内置锁定版本 npm，并严格限制依赖安装脚本；新脚本需要桌面版审核更新。
- 桌面应用通过安装包发布；运行时升级与桌面升级相互独立。当前安装包尚未签名。
